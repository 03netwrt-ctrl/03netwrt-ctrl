**03NET** — small-network lab & tinkering from Kabupaten Bandung, Indonesia.

- 🔧 Custom Android kernels — e.g. Droidspaces-enabled kernel for the Galaxy Z Flip3
- 📱 Android rooting, Magisk modules & system tweaks
- 🛡️ Branded VPN apps on the Mihomo (Clash Meta) core
